# OceanBrown Website and Administration

Production OceanBrown public website and protected content administration dashboard.

## Features

- Responsive public company website
- Light and dark modes
- Protected administration dashboard at `/admin`
- Database-backed content and inquiry management
- Draft, scheduled, published, and coming-soon workflows
- SEO metadata management

Built with Next.js/Vinext, React, TypeScript, Drizzle ORM, and Cloudflare D1.
